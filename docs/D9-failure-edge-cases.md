# Deliverable 9: Failure & Edge-Case Matrix — BuildWise

> [!NOTE]
> Robust software is defined by how gracefully it degrades under adverse conditions. This matrix outlines system behaviors, user-facing communications, and automated fallback mechanisms for all failure modes and edge scenarios across the BuildWise marketplace.

---

## 1. System Error & Edge-Case Matrix

| # | Scenario | System Behavior | User-Facing Message | Fallback Mechanism |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **Customer creates project without AI** | Standard form validation accepts inputs directly; no AI endpoints invoked. | None (standard manual flow). | Customer completes standard step-by-step form (Area, Budget, Timeline, District). |
| **2** | **Customer enters incomplete requirements** | Requirement Analyzer detects missing fields via schema validation. | *"We noticed you didn't specify plot area or number of floors. Would you like to add these now?"* | System prompts customer with high-yield follow-up questions before saving as draft. |
| **3** | **Customer enters unrealistic budget** (e.g., ₹10L for 4,000 sq.ft villa) | Cost Estimator flags budget variance exceeding -40% against regional baseline. | *"Your entered budget is significantly below current Goa construction averages (~₹1,800/sq.ft). Consider adjusting your budget or reducing built-up area."* | Shows benchmark comparison with option to proceed with warning tag or run Budget Optimizer. |
| **4** | **AI Requirement Analyzer is down / times out** | Circuit breaker catches 4.5s timeout; logs failure in `audit_logs`. | *"AI requirement assistant is currently taking a rest. You can fill in the project form directly."* | Seamlessly transitions user into standard structured form without losing entered text. |
| **5** | **AI Cost Estimator fails** | Regressor model throws error; circuit breaker activates. | *"AI cost estimation is temporarily unavailable. Based on historical Goa averages, standard construction ranges between ₹1,800–₹2,400/sq.ft."* | Fallback static lookup table calculates approximate range based on area × Goa district average. |
| **6** | **AI Budget Optimizer fails** | Optimization engine returns exception or timeout. | *"Automated budget optimization is currently unavailable. Review our standard cost-saving checklist below."* | Displays standard value-engineering guide (e.g., vitrified tile swaps, phasing non-structural works). |
| **7** | **Professional deletes / deactivates account** | Active quotations marked `withdrawn`; ongoing awarded projects trigger dispute review; profile hidden from search. | Customer: *"Contractor [Name] has deactivated their account. Platform support has been alerted to review your project."* | If project is in progress, admin is paged; funds in escrow remain locked until resolution. |
| **8** | **No professionals in requested location** | Search query returns zero matches for specific taluka. | *"No contractors currently listed in [Location]. Showing 8 verified professionals from adjacent Goa regions who serve your area."* | Automatically expands search radius to adjacent districts with clear badge: *"Serves [Location] from nearby"*. |
| **9** | **Duplicate enquiry by same professional** | Unique constraint `(project_id, professional_id)` blocks second insertion at DB level. | *"You have already submitted an enquiry for this project. Check your Sent Proposals."* | HTTP 409 Conflict returned; no lead credits deducted for second attempt. |
| **10** | **Quotation expires** | Cron / status check compares `validity_date` against `NOW()`; marks status `expired`. | *"This quotation expired on [Date]. You can request a refreshed quote from the contractor."* | "Request Quotation Extension" CTA button appears on the comparison screen. |
| **11** | **Quotation revised by professional** | Creates new version record (`version = version + 1`); marks old version `superseded`. | *"Contractor submitted Rev 2 with updated material costs. View diff."* | Visual diff view highlighting line-item changes between versions. |
| **12** | **Customer uploads unsupported doc format** (e.g., .exe, .zip) | FastAPI MIME-type validator rejects file before upload to Supabase. | *"Unsupported file format. Please upload PDF, Excel (.xlsx), Word (.docx), or image files."* | Upload rejected with HTTP 415; clean error toast displayed. |
| **13** | **OCR fails to extract text from blurry image** | Image pre-processor detects low DPI / contrast; OCR confidence score < 0.30. | *"We couldn't clearly read this document. Please upload a clearer scan, or enter quotation details manually."* | Job marked `FAILED_UNREADABLE`; opens side-by-side manual entry form. |
| **14** | **Quotations contain conflicting measurement units** (e.g., sq.m vs. sq.ft) | Normalization engine converts standard metric units to imperial (1 sq.m = 10.764 sq.ft). | *"Units standardized to sq.ft for comparison (converted from original sq.m)."* | Footnote indicates source unit and conversion factor applied. |
| **15** | **AI quotation extraction has low confidence** | Extracted line item has confidence < 0.70. | *"Please verify highlighted line items against your original document."* | Low-confidence rows rendered in amber with instant click-to-edit input box. |
| **16** | **Customer uploads duplicate quotation document** | SHA-256 hash check matches an existing document for the same project. | *"This document appears to be identical to a previously uploaded file. Processing skipped."* | Redirects user to existing extraction result without duplicating storage or compute. |
| **17** | **Supplier runs out of stock / changes availability** | Product status updated to `out_of_stock`. | *"This item is temporarily out of stock. View 3 similar alternatives from other Goa suppliers."* | "Find Alternative Vendors" CTA displays matching items in the same price tier. |
| **18** | **Project cancelled by customer** | Project status transitions to `cancelled`; active bidders notified; pending enquiries refunded. | Contractors: *"Project [Title] was cancelled by the owner. 10 lead credits have been refunded to your wallet."* | Lead credits automatically credited back to participating professionals. |
| **19** | **Professional stalls project updates** | No site log posted for > 14 days on active project. | Customer & Contractor: *"No site updates logged in 14 days. Request status update."* | Automated email/SMS ping sent to contractor; alert banner placed on customer dashboard. |
| **20** | **Concurrent conflicting project updates** | Optimistic concurrency control via `updated_at` timestamp check in DB update queries. | *"The record was updated by another party. Refreshing with latest data."* | Client refreshes state and allows user to re-apply non-conflicting changes. |
| **21** | **Unauthorized access attempt** (Customer accesses private contractor wallet) | Supabase RLS and FastAPI RBAC intercept request; 403 Forbidden raised. | *"Access Denied: You do not have permission to view this resource."* | Request blocked; security incident logged in `audit_logs` with IP and user ID. |
| **22** | **Insufficient data for AI Demand Prediction** | Sample size in region < 20 published projects. | *"Demand forecasting requires a minimum of 20 historical projects in this region. Showing observed historical counts."* | Suppresses speculative ML curve; displays factual bar chart with sample size disclaimer. |
| **23** | **Complete AI subsystem outage** | All AI microservices unreachable. | *"AI tools are temporarily offline for routine maintenance. All marketplace search, project posting, and quotation features remain fully functional."* | Application operates seamlessly in pure marketplace mode without interruption. |
